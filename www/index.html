MiniHTTPd

Servidor Web HTTP/1.1 de Alto Rendimiento, Conexiones Persistentes y I/O Event-Driven

Arquitectura del Sistema

MiniHTTPd es un servidor web estático liviano implementado en lenguaje C11 para entornos Linux. Diseñado desde cero utilizando llamadas al sistema posix nativas para maximizar la eficiencia y el control de recursos a bajo nivel.

Características Técnicas

Sockets TCP & I/O

Manejo directo de sockets POSIX en IPv4, configurados en modo no bloqueante para una transmisión eficiente de datos.

Multiplexación epoll

Uso de epoll(7) en modo Edge-Triggered (ET) o Level-Triggered (LT) para escalar eficientemente a miles de conexiones concurrentes.

HTTP/1.1 Keep-Alive

Soporte para conexiones persistentes mediante encabezados Connection: keep-alive, reduciendo el overhead de handshakes TCP.

Seguridad de Rutas

Resolución segura de rutas de archivos con realpath() para prevenir vulnerabilidades de Directory Traversal (../).

Especificación del Servidor C11

El núcleo del servidor ejecuta una arquitectura monohilo asíncrona basada en eventos, utilizando estructuras de datos optimizadas para la lectura e interpretación rápida de peticiones HTTP.

  • Estándar C: C11 (GCC / Clang).
  • Métodos Soportados: GET.
  • Códigos de Estado HTTP: 200 OK, 400 Bad Request, 403 Forbidden, 404 Not Found, 405 Method Not Allowed, 500 Internal Server Error.
  • Transmisión de Datos: Mapeo directo y resolución de tipos MIME basada en la extensión del archivo.
